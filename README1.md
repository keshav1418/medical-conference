## 🚧 Project Status: On Hold

Development of this project is currently **paused**. The frontend is complete
and fully functional, but I had to stop active work due to academic and time
commitments.

### Why the project is paused
I built this project alongside my studies. As my academic workload increased,
I could no longer give it the time it needed, so I paused development after
finishing the core frontend. The project is not abandoned, and I plan to
resume it in the future.

### What is completed
- Multi-page navigation with React Router DOM
- Home, Conferences, Newsroom, Partners, Sponsorship, Contact, and Auth pages
- Modal-based "View Details" and registration flows
- Registration page with multi-currency support and pricing tables
- Consistent blue-and-white theme using CSS custom properties
- Shared Navbar and Footer layout

### Planned for future updates
- Backend integration (API and database)
- Real authentication and user accounts
- Payment gateway integration for registration
- Admin dashboard to manage conferences and registrations
- Speaker and schedule pages

### Using this project
The code is stable and can be run locally by following the setup steps above.
Feel free to explore it, fork it, or use it as a reference for your own work.
